# Working agreement

## Start of every session

Run `git pull` before doing anything else. The daily bot commits new data every
morning, so the local copy is almost always behind.

## After completing a change

When you finish a change I asked for, commit it with a short plain-English
message and push to GitHub. Don't wait to be asked.

## When a pull or push fails

If a pull or push fails because of conflicting changes, resolve the conflict and
explain what happened in one sentence.
